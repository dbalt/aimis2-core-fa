## Why

Дерево drill-down в факторном анализе раздувается ненужными ветками, где все факторы положительные. Это приводит к избыточной загрузке данных из ClickHouse, раздуванию итогового JSON-результата и бесполезной AI-суммаризации.

## What Changes

- **SUM-ветка:** если все факторы, прошедшие Pareto, положительные — дриллим каждый из них (и иерархия, и аналитика). Если есть отрицательные — дриллим только отрицательные (как сейчас).
- **ANALYT-ветка:** включаем `flg_positive=True` в `get_factors`, применяем ту же логику `all_positive`.
- **collect_for_summary:** в итоговую фактуру включаем только ветки с хотя бы одним негативным impact на каком-то уровне. Ветки без негатива — включают только текущий уровень без `details`.
- **MULTI/RATIO ветки:** без изменений (уже дриллят оба компонента).

**Результат:**
- **-33%** запросов к ClickHouse (отсекаются позитивные ветки на глубине ≥ 2)
- **-38%** объём JSON фактуры
- 0 бесполезных веток (всё позитивное + глубина ≥ 2)
- Все негативные инсайты сохранены
