- **подстатья** → `type=sum` у родителя.
- **разрез** → переносится в `analyt_metadata` родителя.
- **тариф** + **база** → `type=multi` у родителя.
- **upr_cube_codes** → массив строк УпрКуба для агрегации значения узла.
