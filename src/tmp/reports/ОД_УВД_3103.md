## Факторный анализ отклонения ОД до резервов УВД

### Общее саммари
По итогам анализа выявлено, что фактическое значение операционных доходов (ОД) до резервов УВД превысило плановое на 444,8 млн руб. Основной вклад в положительное отклонение обеспечили доходы по продуктам банка, однако этот эффект был частично нивелирован существенным снижением по ряду направлений. Ключевыми негативными факторами стали:

1. Резкое падение доходов по потребительским кредитам (вклад −10,7 млрд руб.).
2. Снижение по кредитным картам (вклад −5,7 млрд руб.).
3. Падение по мобильному банку (вклад −0,8 млрд руб.).

Совокупный негативный вклад этих факторов составил около 17,2 млрд руб., что было частично компенсировано положительной динамикой по другим компонентам.

- **Вывод:** Основной негатив связан с резким сокращением объёмов продаж.

#### 2. Кредитные карты

- **Ключевые причины:**
    - **Количество продаж:** План — 6049 ед., факт — 4267 ед. (отклонение −1782 ед.), вклад −5 449 273,44 руб.

- **Вывод:** Основной негатив обусловлен падением объёмов продаж.

#### 3. Мобильный банк
- **Вклад в отклонение:** −765 513,16 руб.
- **Ключевые причины:**
    - **Количество продаж:** План — 3060 ед., факт — 1328 ед. (отклонение −1732 ед.), вклад −734 953,24 руб.

- **Вывод:** Основной негатив связан с сокращением объёмов продаж.

### Итоговые выводы
- Ключевой драйвер негативного отклонения — резкое сокращение объёмов продаж по потребительским кредитам, кредитным картам и мобильному банку.
- Влияние тарифов было минимальным и не компенсировало падение объёмов.
- Для улучшения результатов рекомендуется усилить работу по продвижению данных продуктов и пересмотреть стратегию продаж.
