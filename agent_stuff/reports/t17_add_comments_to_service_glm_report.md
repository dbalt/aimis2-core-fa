## Принципы комментирования

1. **Docstring на каждую функцию** — назначение, параметры, возвращаемое значение, особенности
2. **Вложенные функции** — явно описано что замыкается, зачем нужна, рекомендация не вызывать напрямую
3. **Инлайн-комментарии** — только для неочевидных решений (формулы, порядок операций, edge cases)
4. **Разделители секций** — `# ---` для визуального отделения логических блоков
5. **Без избыточности** — не комментировался очевидный код (присвоения, простые if)
