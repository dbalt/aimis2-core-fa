## Входные данные

### Задача (11_data_access_combine_conditions__structured.md)
Задача описывала требования к реализации иерархической системы классов для представления SQL-условий фильтрации:

1. **ConditionSet** — типизированный контейнер для фильтрации по столбцам
2. **ConditionOr** — контейнер для условий с оператором OR
3. **ConditionAnd** — контейнер для условий с оператором AND
4. **Функция reduce_condition** — оптимизация структуры условий

Основные правила редукции:
- `ConditionAnd(ConditionSet1, ConditionSet2)` → `ConditionSet` (пересечение значений)
- `ConditionOr(ConditionSet1, ConditionSet2)` → `ConditionSet` (объединение значений, если столбцы совпадают)
- Рекурсивная редукция снизу вверх
- Итеративная редукция для >2 элементов

### Исходный код (conditions.py)
Модуль содержит следующие компоненты:

**Абстрактные классы:**
- `ConditionBase` — базовый интерфейс для всех условий

**Основные классы:**
- `ConditionSet` — контейнер для простых фильтров
- `_ConditionContainer` — базовый класс для контейнеров
- `ConditionOr` — OR-контейнер
- `ConditionAnd` — AND-контейнер

**Вспомогательные функции:**
- `_normalize_value` — нормализация к списку
- `_denormalize_value` — денормализация (список из 1 элемента → элемент)
- `_intersect_values` — пересечение значений
- `_union_values` — объединение значений
- `_has_same_columns` — проверка совпадения столбцов
- `_reduce_condition_and_condition_set` — редукция AND
- `_reduce_condition_or_condition_set` — редукция OR
- `_iterative_reduce` — итеративная редукция
- `_reduce_recursively` — рекурсивная редукция
- `reduce_condition` — публичная функция редукции

**Иерархия классов:**
```
ConditionBase (ABC)
    ├── ConditionSet
    ├── _ConditionContainer
    │   ├── ConditionOr
    │   └── ConditionAnd
```

**Ключевые наблюдения:**
1. `ConditionSet` реализует простой словарь-обёртку для фильтрации по столбцам
2. `ConditionOr` и `ConditionAnd` наследуются от общего `_ConditionContainer`
