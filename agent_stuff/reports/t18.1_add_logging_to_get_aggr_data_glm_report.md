# Отчёт: Добавление логирования в aggr.py (Task 18.1)

## Дата: 2026-04-26

## Общее описание

Добавлены вызовы функций логирования во все методы класса `DataAccess` и метод `_build_query` в модуле `src/libfa2/data_access/aggr.py`. Логгер получается вызовом `get_logger()` из `sdk.core.logging` в начале каждого метода.

## Использованные уровни логирования

| Уровень | Количество вызовов | Назначение |
|---------|-------------------|------------|
| `lgr.debug()` | 7 | Трейс параметров, промежуточные этапы построения SQL, сформированный запрос |
| `lgr.info()` | 3 | Вход/выход из методов, результат выполнения запроса |
| `lgr.error()` | 1 | Ошибка при выполнении SQL-запроса |
