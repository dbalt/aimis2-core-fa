# Отчет 23.1: Логирование в FA сервере

## Измененный файл
`src/libfa2/fa_server.py`

## Добавленные вызовы логирования

### lgr.info — развилки и переходы между блоками логики
| Место | Сообщение |
|-------|-----------|
| Начало обработки action | `Processing get_deviation_summary: code=..., dt=...` |
| Найдены кэшированные результаты | `Cached results found for code=..., dt=...` |
| Кэша нет, переход к расчету | `No cached results, proceeding to calculate: code=..., dt=...` |
| Десериализация параметров | `Deserialized calc_params for code=..., rep_dt set to ...` |
| Перед расчетом отклонений | `Starting deviation calculation: code=..., dt=...` |
| После расчета отклонений | `Deviation calculation completed: code=..., dt=...` |
| Перед саммаризацией | `Starting summarization: code=..., dt=...` |
| После саммаризации | `Summarization completed: code=..., dt=..., summary length=...` |
| Перед возвратом результата | `Returning summary: code=..., dt=...` |

### lgr.debug — трейс значений переменных
| Место | Сообщение |
|-------|-----------|
| Входящий request_payload | `request_payload: {...}` |
| Длина кэшированного summary | `CACHED summary length=...` |
| Загрузка метаданных | `Metadata loaded for code=...` |
| Результат collect_for_summary | `Collected data for summary, keys=[...]` |

### lgr.warning — некритичные ситуации
| Место | Сообщение |
|-------|-----------|
| Ошибка сохранения результатов | `Failed to save results for code=..., dt=...: ...` |
| Неподдерживаемый action | `Unsupported action received: ...` |

### lgr.exception — критичные ошибки перед выбросом исключения
| Место | Сообщение |
|-------|-----------|
| Метаданные не найдены | `Metadata not found for code="...": ...` |
| Ошибка саммаризации | `Summarization failed: code=..., dt=...: ...` |
