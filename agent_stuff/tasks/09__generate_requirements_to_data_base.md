Сформулируй документ-требования к структуре таблицы в базе данных, в которой могла бы храниться информация (@agent_stuff/misc/database_struct_requirements.md)

Документ должен содержать:

- Очень краткое описание структуры метаданных разложения на компоненты аналитической структуры и спуска по иерархии, с краткими примерами

- Требования к таблице (должны быть столбцы, которые есть в метаданных иерархии в некоторых узлах, собираемых из БД в свойстве __query__ + столбцы указанные в метаданных разложения по аналитической структуре + отчетная дата (rep_dt/report_dt/dt) + столбцы со значением плана (plan_amt/val_plan) и факта (fact_amt/val_fact)

- Нужно сгенерировать пример такой таблицы, на основе примеров метаданных из этого же документа с заполнением строк данными комплементарными этим примерам
