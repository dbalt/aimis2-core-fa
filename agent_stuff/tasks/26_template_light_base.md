В папке src/tmp/template_lite лежат json файлы заполненные с помощью утилиты по составлению сценария обхода данных для факторного анализа

изучи структуру, спроектируй классы для представления этой информации. Поля, по которым значений 2-5 нужно упаковать в enum classes.

Также нужно написать функцию десериализации данных из этого json файла в некую структуру обьектов спроектированных классов. `def get_from_template_lite_json()`

Все классы и функции нужно разместить в модуль adhoc.template_lite (src/adhoc/template_lite)

тесты нужно разместить в adhoc.template_lite.tests (src/adhoc/template_lite/tests)
