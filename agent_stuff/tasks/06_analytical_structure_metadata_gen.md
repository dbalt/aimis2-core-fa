Проанализируй @agent_stuff/docs/fa_descr.md, раздел 2

Предложи вариант структуры хранения метаданных об алгоритмов разложения показателей по аналитическим разрезам в формате JSON

доп инфа:

каждый показатель со своей иерархией, аналитическими разрезами и значениями плана и факта + отчетная дата, все лежат в одной таблице БД

- Для каждого аналитического разреза должны быть определены __name__ (отображаемое имя) и __code__ - наименование столбца в таблице в БД соответствующего данному аналитическому разрезу

- Каждый алгоритм обхода должен иметь свой __id__ (тупо int. и все, не надо привязывать к показателю, не нужно name и description)

- На каждом шаге алгоритма обхода может быть задействован один или сразу несколько аналитических разрезов (то есть может быть требования на определенном шаге раскладывать по пересечению например (сегмент + продукт))

Сгенерируй описание в структурированном и понятном формате, также сгенерируй пример в котором есть несколько алгоритмов разложения по аналитическим разрезам

Сохрани предлагаемое описание в файле @agent_stuff/docs/fa_analytical_structure_metadata.md
