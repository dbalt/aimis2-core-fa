В @agent_stuff/docs/factor_analysis__analytical_drill_metadata.md и @agent_stuff/docs/factor_analysis__hieararchy_drill_metadata.md  описаны спецификации метаданных для факторного анализа спуском по иерархии и разложения по аналитическим разрезам.

Описано так, что эти два типа метаданных это полностью независимые сущности

Концепция поменялась, и теперь метаданные разложения по аналитическим разрезам являются отдельным свойством узла иерархии показателей. То есть на разных узлах одной иерархии могут быть разные метаданные разложения по аналитическим разрезам (либо не быть вообще).

Имплементация модулей работы с метаданными:

- libfa2.analyt_struct_metadata (@src/libfa2/analyt_struct_metadata/): код для работы с метаданными разложения по аналитическим разрезам
- libfa2.hier_metadata (@src/libfa2/hier_metadata/): код для работы с метаданными разложения по иерархии
