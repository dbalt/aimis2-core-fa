# Метод цепных подстановок

Нужен для расчета влияния драйверов на отклонение верхнеуровнего показателя

Рассмотрим пример:

Показатель | План | Факт | Отклонение
-- | -- | -- | --
Комиссионный доход | 500000 | 430000 | -70000
-- ставка коммиссии (коэффициент) | 0.417% | 0.37% | 
-- объем операций (база)| 120000000 | 116000000 | 

Влияние базы считается по такой формуле: коэффициент план * база факт - коэффициент план * база план

Влияение коэффициента считается обратным счетом, вычитаем из отклонения верхнеуровнего показателя влияние базы

Для данного примера:
- влияние обьема операций = (116000000 * 0.417 / 100) - (120000000 * 0.37 / 100) === -16667 
- влияние ставки комиссий обратным счетом = -70000 - (-16667) === -53333
