# Метод цепных подстановок

## Назначение

Метод цепных подстановок используется для расчета влияния драйверов на отклонение верхнеуровневого показателя.

Драйвер — это показатель, который влияет на результат через умножение на базу:
```
Результат = Коэффициент × База
```

---

## Основные принципы

При разложении отклонения по драйверам используется следующий подход:

1. **Влияние базы** рассчитывается прямым способом — заменяем плановое значение базы на фактическое, оставляя коэффициент плановым
2. **Влияние коэффициента** рассчитывается обратным счетом — вычитаем из общего отклонения уже полученное влияние базы

---

## Формулы

### Влияние базы
```
Влияние_базы = Коэффициент_план × База_факт - Коэффициент_план × База_план
             = Коэффициент_план × (База_факт - База_план)
```

### Влияние коэффициента
```
Влияние_коэффициента = Отклонение_показателя - Влияние_базы
```

---

## Практический пример

### Исходные данные

| Показатель | План | Факт | Отклонение |
|------------|------|------|------------|
| Комиссионный доход | 500 000 | 430 000 | **-70 000** |
| └─ Ставка комиссии (коэффициент) | 0.417% | 0.370% | — |
| └─ Объем операций (база) | 120 000 000 | 116 000 000 | — |

### Расчеты

**Шаг 1. Влияние объема операций (базы):**
```
Влияние_базы = 0.417% × 116 000 000 - 0.417% × 120 000 000
             = 483 720 - 500 400
             = -16 680
```

**Шаг 2. Влияние ставки комиссии (коэффициента) — обратным счетом:**
```
Влияние_коэффициента = -70 000 - (-16 680)
                     = -53 320
```

### Результат

| Показатель | План | Факт | Влияние на отклонение |
|------------|------|------|-----------------------|
| Комиссионный доход | 500 000 | 430 000 | **-70 000** |
| └─ Ставка комиссии (коэффициент) | 0.417% | 0.370% | **-53 320** |
| └─ Объем операций (база) | 120 000 000 | 116 000 000 | **-16 680** |

### Проверка

Сумма влияний должна быть равна общему отклонению:
```
-53 320 + (-16 680) = -70 000 ✓
```

---

## Выводы по примеру

- Общее отрицательное отклонение: **-70 000**
- Основной драйвер негатива: **ставка комиссии** (-53 320, ~76% от негатива)
- Второстепенный драйвер: **объем операций** (-16 680, ~24% от негатива)
