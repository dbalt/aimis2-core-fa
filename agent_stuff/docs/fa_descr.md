# Общее описание функционала факторного анализа

Факторный анализ подразумевает раскладывание отклонений факта от плана для определенного финансового показателя по компонентам.


## 1. Разложение по компонентам иерархии

Анализируемый финансовый показатель может состоять из суммы других финансовых показателей, которые тоже могут раскладываться на отдельные финансовые показатели. То есть финансовые показатели составляют иерархию.
 

Помимо этого, определенные финансовые показатели могут быть представлены как умножение некоего коэффициента на некую базу. Например __[Процентный доход]__ = __[процентная ставка (коэффициент)]__ * __[Обьем выданных долговых финансовых инструментов (база)]__. Для таких показателей обычно известна величина самого показателя и величина базы, а коэффициент рассчитывается обратным счетом. коэффициент и база при этом являются драйверами. База может сама быть составным финансовым показателем.

_Структура метаданных с помощью которых описывается иерархия показателей описана в @agent_stuff/docs/fa_hierarcjy_metadata.md_

Разложением по компонентам иерархии является расчет влияния на общее отклонение на каждом конкретном узле иерархии. 

Если показатель является суммируемым компонентом, то его влияние это просто отклонение факта от плана.

Если показатель является драйвером, то его влияние рассчитывается методом цепных подстановок (_описано в @agent_stuff/docs/chain_subs.md_)

#### Пример 1.1

Иерархия показателей
```
Чистый процентный доход
    |-- Процентный доход
    |       |-- ставка процентного дохода (коэффициент)
    |       |-- Обьем требований по долговым финансовым инструментам (база)
    |
    |-- Процентный расход
    |        |-- ставка процентного расхода (коэффициент)
    |        |-- Объем обязательств по долговым финансовым инструментам (база)
    |
    |-- Прочие компоненты включенные в ЧПД
```

Таблица с числовым примером:

| Показатель | План | Факт | Влияние на отклонение |
|------------|------|------|------------------------|
| Чистый процентный доход | 700 | 500 | -200 |
| ├── Процентный доход | 1000 | 750 | -250 |
| │   ├── Ставка процентного дохода | 0,0200 | 0,0188 | -75 |
| │   └── Объем требований по долговым фин. инструментам | 50 000 | 40 000 | -175 |
| ├── Процентный расход | -600 | -450 | +150 |
| │   ├── Ставка процентного расхода | 0,0120 | 0,0100 | +90 |
| │   └── Объем обязательств по долговым фин. инструментам | -50 000 | -45 000 | +60 |
| └── Прочие компоненты, включенные в ЧПД | 300 | 200 | -100 |

**Примечание к примеру:**
- Доходы и объем требований положительные, расходы и объем обязательств отрицательные
- План по Чистому процентному доходу не выполняется: 500 < 700 (отклонение -200)
- План по Процентному расходу выполняется (факт больше плана): -450 > -600 (положительное влияние +150, так как расходы ниже запланированных)
- План по Процентному доходу не выполняется и отклонение (-250) хуже, чем по верхнеуровневому показателю (-200)



## 2. Разложение по аналитическим разрезам

Следующий сценарий это разложение по аналитическим разрезам. 

Данные по план факту показателей доступны в аналитических разрезах (например геоструктура, сегмент, продукт, канал и тд)

Для показателя может быть определен порядок разложения по аналитическим разрезам:
1. сначала по сегменту
2. потом по геоструктуре
3. потом по комбинации продукт + канал


Может быть определено сразу несколько независимых порядков обхода:
- Сначала по геоструктуре потом по сегменту потом по каналу
- Сначала по сегменту потом по продукту

Допустим для примера что порядок такой: сначала по сегменту, потом по продукту

первым уровнем компонент факторного анализа для этого сценария будет расчет величин план/факт/отклонения для показателя в разрезе каждого сегмента
вторым уровнем компонент будет являтся разложение каждого компонента первого уровня в разрезе продуктов.

драйверы не могут быть отдельно разложенными по аналитическим разрезам, только вместе с верхнеуровневым показателям

_Структура метаданных для описания алгоритмов разворота по аналитическим разрезам описана в @agent_stuff/docs/fa_analytical_structure_metadata.md_

#### Пример 2.1

Рассмотрим вымышленный показатель **"Комиссионный доход"** с порядком разложения: сначала по сегментам, потом по геоструктуре.

**Аналитические разрезы:**
- Сегменты: Юридические лица, Физические лица, Прочие
- Геоструктура: Москва, Питер, Сибирь, Дальний Восток, Остальное

**Итоговый уровень - общий по показателю:**

| Показатель | План | Факт | Отклонение |
|------------|------|------|------------|
| Комиссионный доход (всего) | 1000 | 900 | -100 |

План по показателю не выполняется (факт меньше плана на 100).

**Первый уровень разложения - по сегментам:**

| Показатель | План | Факт | Отклонение |
|------------|------|------|------------|
| Комиссионный доход (всего) | 1000 | 900 | -100 |
| ├── Юридические лица | 600 | 650 | +50 |
| ├── Физические лица | 300 | 200 | -100 |
| └── Прочие | 100 | 50 | -50 |

На этом уровне план выполняется по сегменту "Юридические лица" (+50), но не выполняется по "Физические лица" (-100) и "Прочие" (-50).

**Второй уровень разложения - по геоструктуре (для каждого сегмента):**

| Показатель | План | Факт | Отклонение |
|------------|------|------|------------|
| Комиссионный доход (всего) | 1000 | 900 | -100 |
| ├── Юридические лица | 600 | 650 | +50 |
| │   ├── Москва | 200 | 300 | +100 |
| │   ├── Питер | 100 | 95 | -5 |
| │   ├── Сибирь | 80 | 85 | +5 |
| │   ├── Дальний Восток | 70 | 70 | 0 |
| │   └── Остальное | 150 | 100 | -50 |
| ├── Физические лица | 300 | 200 | -100 |
| │   ├── Москва | 100 | 40 | -60 |
| │   ├── Питер | 80 | 75 | -5 |
| │   ├── Сибирь | 50 | 40 | -10 |
| │   ├── Дальний Восток | 40 | 30 | -10 |
| │   └── Остальное | 30 | 15 | -15 |
| └── Прочие | 100 | 50 | -50 |
|     ├── Москва | 30 | 20 | -10 |
|     ├── Питер | 20 | 15 | -5 |
|     ├── Сибирь | 15 | 20 | +5 |
|     ├── Дальний Восток | 10 | 5 | -5 |
|     └── Остальное | 25 | 10 | -15 |

**Примечание к примеру:**
- Общий план по Комиссионному доходу не выполняется: 900 < 1000 (отклонение -100)
- На уровне сегментов: план выполняется только по "Юридические лица" (+50), по остальным сегментам план не выполняется
- На уровне геоструктуры в каждом сегменте есть компоненты с положительным и отрицательным отклонением:
  - В "Юридические лица": план выполняется в Москве (+100), Сибири (+5) и стабилен на Дальнем Востоке (0)
  - В "Физические лица": план не выполняется по всем геоструктурам, наиболее значительное недовыполнение в Москве (-60)
  - В "Прочие": единственное выполнение плана наблюдается в Сибири (+5)




## 3. Общий Алгоритм 

Общий алгоритм заключается в комбинировании вышеописанных подходов + на каждом уровне разложения на компоненты есть условие на то, как отобрать наиболее существенные для данного сценария компоненты, и дальнейшее разложение происходит только для этих самых наиболее существенных компонент.

Обычно происходит поиск компонент по которым не выполнен план + есть условие и алгоритм отбора наиболее существенных (например 3-6 штук, которые покрывают > 80% вклада в негативную составляющую).

Для каждого показателя мы делаем разложение и по первому и по второму методу. В каждой из веток мы определяем наиболее существенные компоненты в отношении которых опять рекурсивно применяем оба метода (если есть еще куда спускаться по иерархии или по аналитическим разрезам).

В итоге получается дерево элементов, в котором узлы это результат какого то одного уровня разложения на компоненты с доп фактурой:
- показатель + комбинация аналитических разрезов + план/факт/влияние на отклонение
- результат разложения на компоненты следующего уровня (наиболее существенные компоненты + сумма их влияния + процент покрытия негативной составляющей)

Каждый путь от вершины до листового элемента соответствует одному из вариантов полного факторного анализа верхнеуровнего показателя, где на разных уровнях могли применяться разные способы разложения на компоненты.


По этой фактуре специальный AI agent сможет сформулировать саммари с выделением наиболее значимых факторов (они могут быть надерганы из разных веток результирующего дерева)
