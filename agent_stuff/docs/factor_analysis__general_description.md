## Общее описание

Факторный анализ — это процесс разложения отклонения факта от плана для финансового показателя по отдельным компонентам с целью выявления ключевых факторов, повлиявших на результат.

**Основная задача:** определить, какие компоненты и в какой степени contributed к общему отклонению от плана.

---

## Ключевые понятия

| Понятие | Описание |
|---------|----------|
| **Финансовый показатель** | Измеримая величина (доход, расход, маржа и т.д.), для которой проводится анализ |
| **План / Факт** | Плановое и фактическое значение показателя за период |
| **Отклонение** | Разница между фактом и планом (Факт - План) |
| **Иерархия показателей** | Древовидная структура, где верхнеуровневый показатель состоит из суммы нижнеуровневых |
| **Суммируемые компоненты** | Компоненты, которые складываются в итоговое значение |
| **Компоненты-множители** | Компоненты, которые влияют на результат через умножение (множитель × база) |
| **База** | Объемный показатель, на который умножается множитель |
| **Множитель** | Нормированный показатель (ставка, процент и т.д.) |
| **Показатель типа ratio** | Показатель, рассчитываемый как отношение компонента-числителя к компоненту-знаменателю (возможен только на верхнем уровне) |
| **Аналитические разрезы** | Измерения для детализации данных (сегмент, геоструктура, продукт, канал и т.д.) |
| **Влияние на отклонение** | Количественная оценка вклада компонента в общее отклонение |

## Типы разложения

### 1. Разложение по компонентам иерархии

Финансовые показатели могут быть организованы в иерархическую структуру двух типов:

#### Тип 1: Суммируемые компоненты
Показатель складывается из суммы других показателей:
```
Чистый процентный доход = Процентный доход + Процентный расход + Прочие компоненты
```

#### Тип 2: Компоненты-множители
Показатель рассчитывается как произведение множителя на базу:
```
Процентный доход = Ставка × Объем выданных долговых инструментов
```

**Правила расчета влияния:**

| Тип компонента | Метод расчета влияния |
|----------------|----------------------|
| Суммируемый | Отклонение = Факт - План |
| Компонент-множитель | Метод цепных подстановок (см. @agent_stuff/docs/algo__chain_substs_method.md) |

> **Примечание:** Метаданные для описания иерархии показателей описаны в @agent_stuff/docs/factor_analysis__hieararchy_drill_metadata.md

#### Тип 3: Показатели типа ratio

Показатель рассчитывается как отношение двух компонентов:

```
ratio = Компонент-числитель / Компонент-знаменатель
```

**Характеристики показателей типа ratio:**

| Характеристика | Описание |
|----------------|----------|
| **Уровень размещения** | Только на верхнем уровне (корневой показатель) |
| **Числитель** | Может состоять из суммируемых компонент или компонентов-множителей |
| **Знаменатель** | Может состоять из суммируемых компонент или компонентов-множителей |

**Пример: COR (Cost of Risk)**

COR (стоимость риска) рассчитывается как отношение расходов на резервы к среднехронологической величине работающих активов:

```
COR = Расходы на резервы / Среднехронологические работающие активы
```

Где:
- **Числитель** — Расходы на резервы (может иметь свою иерархию из суммируемых компонент или компонентов-множителей)
- **Знаменатель** — Среднехронологические работающие активы (может иметь свою иерархию из суммируемых компонент или компонентов-множителей)

**Расчет влияния для показателей типа ratio:**

Отклонение показателя типа ratio рассчитывается как разность фактического и планового значения:

```
Отклонение = COR_факт - COR_план
```

Для факторного анализа отклонения ratio может быть применен метод цепных подстановок для выявления вклада числителя и знаменателя.

### 2. Разложение по аналитическим разрезам

Данные по плану/факту доступны в различных аналитических разрезах:
- Сегмент
- Геоструктура
- Продукт
- Канал продаж
- И другие

#### Порядок разложения

Для каждого показателя может быть определен один или несколько порядков разложения:

**Пример порядка 1:**
1. По сегменту
2. По геоструктуре
3. По комбинации "продукт + канал"

**Пример порядка 2 (альтернативный):**
1. По геоструктуре
2. По сегменту
3. По каналу

#### Ограничения

- **Компоненты-множители не могут быть отдельно разложены по аналитическим разрезам** — только вместе с верхнеуровневым показателем
- Разложение происходит рекурсивно: сначала по первому измерению, затем каждый результат — по второму, и т.д.

> **Примечание:** Метаданные для описания алгоритмов разворота по аналитическим разрезам описаны в @agent_stuff/docs/factor_analysis__analytical_drill_metadata.md

## Общий алгоритм факторного анализа

### Схема алгоритма

```
┌─────────────────────────────────────────────────────────────┐
│                    Вход: финансовый показатель              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
            ┌─────────────────────────────────────────┐
            │  Параллельное разложение двумя методами  │
            ├─────────────────────────────────────────┤
            │  1. По компонентам иерархии              │
            │  2. По аналитическим разрезам            │
            └─────────────────────────────────────────┘
                              │
                              ▼
            ┌─────────────────────────────────────────┐
            │  Отбор наиболее существенных компонент  │
            │  - Компоненты с невыполненным планом    │
            │  - Топ-N по вкладу в негатив (например, │
            │    3-6 шт., покрывающих >80% негатива)  │
            └─────────────────────────────────────────┘
                              │
                              ▼
            ┌─────────────────────────────────────────┐
            │     Рекурсивное разложение для каждого   │
            │     отобранного компонента (если есть   │
            │          куда спускаться дальше)         │
            └─────────────────────────────────────────┘
                              │
                              ▼
            ┌─────────────────────────────────────────┐
            │    Формирование дерева факторов с       │
            │    метаданными для AI-анализа           │
            └─────────────────────────────────────────┘
```

### Результат

Формируется **дерево элементов**, где:
- **Узел** — результат одного уровня разложения с метаданными:
  - Показатель
  - Комбинация аналитических разрезов
  - План / Факт / Влияние на отклонение
  - Дочерние компоненты (наиболее существенные)
  - Сумма их влияния
  - Процент покрытия негативной составляющей
- **Путь от корня до листа** — полный вариант факторного анализа с комбинацией разных методов на разных уровнях

### Использование результата

Специальный AI-агент анализирует дерево факторов и формирует **суммарный отчет** с выделением наиболее значимых факторов (могут быть взяты из разных веток дерева).

## Примеры

### Пример 1: Разложение по иерархии

#### Иерархия показателей

```
Чистый процентный доход
    ├── Процентный доход
    │   ├── Ставка процентного дохода (множитель)
    │   └── Объем требований по долговым фин. инструментам (база)
    │
    ├── Процентный расход
    │   ├── Ставка процентного расхода (множитель)
    │   └── Объем обязательств по долговым фин. инструментам (база)
    │
    └── Прочие компоненты, включенные в ЧПД
```

#### Результаты анализа

| Показатель | План | Факт | Влияние |
|------------|------|------|---------|
| **Чистый процентный доход** | **700** | **500** | **-200** |
| ├── Процентный доход | 1000 | 750 | -250 |
| │   ├── Ставка процентного дохода | 0,0200 | 0,0188 | -75 |
| │   └── Объем требований по долговым фин. инструментам | 50 000 | 40 000 | -175 |
| ├── Процентный расход | -600 | -450 | +150 |
| │   ├── Ставка процентного расхода | 0,0120 | 0,0100 | +90 |
| │   └── Объем обязательств по долговым фин. инструментам | -50 000 | -45 000 | +60 |
| └── Прочие компоненты, включенные в ЧПД | 300 | 200 | -100 |

#### Ключевые наблюдения

- **План по ЧПД не выполняется:** 500 < 700 (отклонение -200)
- **План по расходам выполняется:** -450 > -600 (положительное влияние +150, расходы ниже плана)
- **Основной компонент-множитель негатива:** Процентный доход (-250), который превышает общее отрицательное отклонение (-200)

### Пример 2: Разложение по аналитическим разрезам

#### Контекст
- **Показатель:** Комиссионный доход
- **Порядок разложения:** Сначала по сегментам, затем по геоструктуре
- **Сегменты:** Юридические лица, Физические лица, Прочие
- **Геоструктура:** Москва, Питер, Сибирь, Дальний Восток, Остальное

#### Уровень 0: Общий итог

| Показатель | План | Факт | Отклонение |

| Комиссионный доход (всего) | 1000 | 900 | **-100** |

| Показатель | План | Факт | Отклонение |
|------------|------|------|------------|
| Комиссионный доход (всего) | 1000 | 900 | -100 |
| ├── Юридические лица | 600 | 650 | **+50** ✓ |
| ├── Физические лица | 300 | 200 | **-100** ✗ |
| └── Прочие | 100 | 50 | **-50** ✗ |

#### Уровень 2: Разложение по геоструктуре

| Показатель | План | Факт | Отклонение |
|------------|------|------|------------|

| ├── Юридические лица | 600 | 650 | +50 |
| │   ├── Москва | 200 | 300 | **+100** ✓ |
| │   ├── Питер | 100 | 95 | -5 |
| │   ├── Сибирь | 80 | 85 | **+5** ✓ |
| │   ├── Дальний Восток | 70 | 70 | 0 |
| │   └── Остальное | 150 | 100 | -50 |
| ├── Физические лица | 300 | 200 | -100 |
| │   ├── Москва | 100 | 40 | **-60** ✗ |
| │   ├── Питер | 80 | 75 | -5 |
| │   ├── Сибирь | 50 | 40 | -10 |
| │   ├── Дальний Восток | 40 | 30 | -10 |
| │   └── Остальное | 30 | 15 | -15 |
| └── Прочие | 100 | 50 | -50 |
|     ├── Москва | 30 | 20 | -10 |
|     ├── Питер | 20 | 15 | -5 |

| Сегмент | Статус плана | Основные компоненты |

### Пример 3: Показатель типа ratio (COR)

#### Контекст
- **Показатель:** COR (Cost of Risk) — стоимость риска
- **Формула:** COR = Расходы на резервы / Среднехронологические работающие активы
- **Назначение:** Оценка стоимости риска как доли расходов на резервы в работающих активах

#### Структура COR

```
COR (Cost of Risk)
    ├── Расходы на резервы (числитель)
    │   ├── Результаты от резервов по кредитам (суммируемые)
    │   │   ├── Резервы по корпоративным кредитам
    │   │   ├── Резервы по розничным кредитам
    │   │   └── Резервы по кредитам МСБ
    │   └── Резервы по прочим активам (суммируемые)
    │
    └── Среднехронологические работающие активы (знаменатель)
        ├── Кредитный портфель (суммируемые)
        │   ├── Корпоративные кредиты
        │   ├── Розничные кредиты
        │   └── Кредиты МСБ
        └── Прочие работающие активы (суммируемые)
```

#### Результаты анализа

| Показатель | План | Факт | Влияние |
|------------|------|------|---------|
| **COR, %** | **2,5%** | **2,8%** | **+0,3%** |
| ├── Расходы на резервы (числитель) | 250 | 350 | +100 |
| │   ├── Резервы по корпоративным кредитам | 150 | 200 | +50 |
| │   ├── Резервы по розничным кредитам | 80 | 120 | +40 |
| │   └── Резервы по кредитам МСБ | 20 | 30 | +10 |
| └── Среднехронологические работающие активы (знаменатель) | 10 000 | 12 500 | +2 500 |

#### Расчет значений

**План:**
- COR_план = 250 / 10 000 = 0,025 (2,5%)

**Факт:**
- COR_факт = 350 / 12 500 = 0,028 (2,8%)

**Отклонение:**
- ΔCOR = 2,8% - 2,5% = +0,3%

#### Факторный анализ отклонения COR

Для выявления вклада числителя и знаменателя может быть применен метод цепных подстановок:

| Шаг | Числитель | Знаменатель | COR | Влияние |
|------|-----------|------------|-----|---------|
| 1 (базис) | 250 | 10 000 | 2,50% | — |
| 2 (числитель факт) | 350 | 10 000 | 3,50% | +1,00% |
| 3 (оба факт) | 350 | 12 500 | 2,80% | -0,70% |

**Вывод:**
- Рост числителя (расходов на резервы) увеличил COR на +1,00%
- Рост знаменателя (работающих активов) уменьшил COR на -0,70%
- Итоговое отклонение: +0,30%

## Сводная таблица методов

| Характеристика | Разложение по иерархии | Разложение по аналитическим разрезам |
|----------------|------------------------|--------------------------------------|
